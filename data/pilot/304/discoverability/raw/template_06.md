# Proposal: character-isotypic Witt classes on the p-adic orbit tower

## Setup
Let Z_p act faithfully on M^n. Put G_k = p^k Z_p, X_k = M/G_k, X = X_0, with maps π_k : M → X_k and q_k : X_k → X. The finite group Γ_k = Z/p^k acts on X_k, and X_k/Γ_k = X. Haar averaging gives H^*(U/G_k; Q) = H^*(U; Q)^{G_k} for G_k-invariant open U. So every X_k is a **rational** cohomology n-manifold, even though dim_Z X_k = n+2 (Yang, Bredon–Raymond–Williams). After passing to M × R^j or M × CP^2 we may assume n = 4m.

## Construction (the invariant)
Write F_k = Rq_{k*} Q_{X_k}[n]. This is a Γ_k-equivariant, Verdier self-dual complex on X. Tensor with Q(μ_{p^k}) and split it by the characters χ ∈ Γ_k^∨ ⊂ Q_p/Z_p:

  F_k ⊗ Q(μ_{p^k}) = ⊕_χ F_χ.

Verdier duality pairs F_χ with F_{χ̄}, so each F_χ is hermitian self-dual. Take its class

  w_χ ∈ W_c(X; Q(μ_{p^k}), herm),

the compactly supported Witt group of self-dual sheaf complexes (Woolf; Balmer's triangular Witt groups). Compatibility as k grows makes w_χ independent of k, so the result is a function

  w : Q_p/Z_p → W_c(X),   σ_χ := signature of w_χ evaluated on a compactly supported test class (equivalently, the L-class pairing; Ranicki–Weiss makes this topologically invariant).

## Lemma (p-adic G-signature equidistribution)
Let X^free be the image of the free points. Faithfulness, Newman's theorem and Baire category make it dense and open in the generic stratum. Then:

(a) **Galois invariance.** σ_χ depends only on the order of χ.

(b) **Free-locus equidistribution.** Over X^free, F_χ is a rank-one local system L_χ. The topological G-signature fact (Gilmer) for free Γ_k-actions, applied to the Witt class localized to X^free via Balmer's 12-term localization sequence, gives σ_χ^free = σ_1^free for every χ.

(c) **Singular-stratum bound.** The complement S = X \ X^free is stratified by the isotropy G_j. By Smith theory, each Fix(G_j) is a mod-p cohomology manifold of dimension ≤ n−2 (codimension ≥ 2). Its Witt contribution to each w_χ lies in the image of W_c(S), and that image is generated by boundedly many classes, independent of k. Hardt's semialgebraic local triviality is used to make the strata tame enough for this.

## How the contradiction arises
1. **Homotopy rigidity.** Maps that are C^0-close to the identity on an ANR are homotopic to it, so some open subgroup G_{k0} acts trivially on H^*_c(M; Q). Hence for k ≥ k0 only the finitely many characters of order ≤ p^{k0} occur in H^{2m}_c(X_k; Q). So

   Σ_{χ ∈ Γ_k^∨} σ_χ = σ(X_k) = σ(X_{k0})   for all k ≥ k0.

2. **Equidistribution.** By (b) and (c),

   Σ_χ σ_χ = p^k · σ_1^free + E_k,   with |E_k| ≤ C,

   where C is independent of k.

3. Comparing the two as k → ∞ forces σ_1^free = 0, and then σ(X_{k0}) = E_k is supported on S.

4. **Choice of test region.** Choose the compactly supported test class to have nonzero signature on the free part, so σ_1^free ≠ 0. Take an invariant compact neighbourhood G·B of a free orbit, then double it, or cross it with a closed manifold of signature 1. This is possible because X^free is open and nonempty. Step 3 then gives a contradiction.

5. If instead one only gets σ_1^free = 0 for every test region, the whole signature lives on S. Induct on dimension: Fix(G_j) carries a faithful action of Z_p/G_j ≅ Z/p^j that extends compatibly in j. That is the same tower structure in dimension ≤ n−2. The base case n ≤ 2 is Pardon's theorem.

## Why this device
Purely cohomological invariants (Yang, Bredon–Raymond–Williams) cannot see faithfulness: rationally the tower is invisible, and integrally it only produces the dimension jump to n+2. A faithful action creates p^k characters, all of which must share the same free-locus signature. Homotopy rigidity, on the other hand, caps the global signature at a value independent of k. The Witt class of sheaves is the right carrier for this:
- it localizes along open/closed decompositions;
- it is topologically invariant;
- it needs only rational Poincaré duality, which the X_k do have.

## Main gap
Step (c), the uniform-in-k bound on the singular-stratum Witt contributions, is the crux; it has not been carried out here. It needs a Witt-theoretic Newman lemma: small subgroups produce no unbounded local signature defects.
