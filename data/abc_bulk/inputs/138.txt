--- MANUSCRIPT: Subset Sum in Time $`O(2^{0.49n})`$ (October-4-2026)
ABSTRACT: We give a uniform randomized classical algorithm for Subset Sum with bounded error and worst-case running time $`O(2^{0.49n})`$ on polynomial-bit inputs in a word-RAM model, where n is the number of input integers. The time bound holds on every random execution.
[theorem] \label{thm:main} There is a uniform randomized classical algorithm $\mathcal A$ for Subset Sum with the following properties in the word-RAM model \eqref{eq:word-length}. For every input with $n\ge2$, the algorithm halts on every execution and outputs the correct answer with probability at least $2/3$. For every fixed positive integer $c$, there are constants $C_c>0$ and $N_c\ge2$ such that every input with $n\ge N_c$ and $b\le n^c$ is processed, on every outcome of the random choices, in at most \[ C_c\,2^{0.49n} \] word operations. The program is not given $c$ and does not depend on $c$.
[proposition] [Capped preliminary search] \label{prop:preliminary} Given fixed transformed weights and targets from \eqref{eq:transformed}, there is a randomized procedure that either returns the correct decision for the original instance or returns \textup{CONTINUE}. On every execution its running time is at most \[ 2^{0.489985n}\operatorname{poly}(n+b+2). \] If $V$ is uniform among the $\lfloor n/2\rfloor$-element subsets and $\mathbb E d(V)>0.01004n$, then the probability of \textup{CONTINUE} is $O(1/n)$, uniformly in the fixed weights.
[proposition] [Filtering moments]\label{prop:filtering-moments} The functions in \eqref{eq:filter-scores} satisfy \begin{equation}\label{eq:continuous-filtering-moments} \begin{split} \int_{\mathbb T}M(x)^2 2^{8.5(\Delta-u(x))}\,dx&<2^{0.5168},\\ \int_{\mathbb T}M(x)^2 2^{8.3(a v(x)-u(x))}\,dx&<2^{0.5168}. \end{split} \end{equation}

--- MANUSCRIPT: A Low-Space Algorithm for Worst-Case Subset Sum (September-26-2026)
ABSTRACT: We give a uniform classical randomized decision algorithm for worst-case Subset Sum. Under every fixed polynomial bound on input-integer bit length, it uses $`\mathop{\mathrm{poly}}\nolimits (n)2^{n/2}`$ time and ordinary $`O(2^{n/5})`$ writable words of $`O(n+b)`$ bits, where b is the largest input bit length. Both resource bounds hold on every execution. The error is one-sided: the algorithm always rejects unsolvable instances and accepts each solvable instance with probability at least 2/3.
[theorem] \label{thm:main} There is a single uniform classical randomized algorithm in this model that never answers YES incorrectly and answers each YES instance correctly with probability at least $2/3$. For every fixed positive integer $c$, there are a constant $A_c>0$ and positive integers $k_c,N_c$ such that, whenever $n\ge N_c$ and $b\le n^c$, every outcome of the algorithm's randomness uses at most \[ A_c n^{k_c}2^{n/2}\quad\text{operations} \qquad\text{and}\qquad A_c(n+b+2)^{15}2^{0.199n}\quad\text{writable words}. \] The algorithm does not depend on $c$.
