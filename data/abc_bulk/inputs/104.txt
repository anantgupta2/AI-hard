FAMILY 104: Quasipolynomial algorithms for mean-payoff, stochastic and parity games
SUBJECT: Theoretical computer science
SUMMARY: Gives deterministic algorithms using $`2^{O((\log(L+2))^2)}`$ bit operations, for complete binary input length L, for ordinary mean-payoff games and two separate extensions. They compute exact values and optimal positional strategies in ordinary games, the nonnegative expectation-of-liminf value set in turn-based stochastic games, and the winning set for nonnegative liminf mean payoff conjoined with parity. Signed rewards, rational chance probabilities, and parity priorities are unrestricted and binary-encoded.
LEAN: yes

--- MANUSCRIPT: Turn-Based Stochastic Mean-Payoff Games in Deterministic Quasipolynomial Time (October-5-2026)
ABSTRACT: We give a uniform deterministic quasipolynomial-time algorithm for finite turn-based stochastic mean-payoff games with signed integer rewards and rational chance-transition probabilities encoded in binary. It computes exactly the vertices of nonnegative value, including value zero, for the expectation of the pathwise liminf mean payoff. The algorithm uses exact rational arithmetic and $`2^{O((\log(L+2))^2)}`$ bit operations, where L is the complete binary input length.
[theorem] \label{thm:main} There are a uniform deterministic Turing machine and an absolute constant $C$ such that, on every valid input described above, the machine outputs exactly $U$ in at most \[ 2^{C(\log_2(L+2))^2} \] bit operations. The bound includes input reading, exact rational arithmetic, and output. Vertices of value zero are included.

--- MANUSCRIPT: Mean-payoff parity games in quasipolynomial time (October-5-2026)
ABSTRACT: We give a uniform deterministic quasipolynomial-time algorithm for mean-payoff parity games. It computes all vertices from which a player can enforce both nonnegative liminf mean payoff and the parity condition, with arbitrary signed binary rewards and unrestricted binary priorities. The running time is $`2^{O((\log(L+2))^2)}`$ bit operations, where L is the complete input length.
[theorem] \label{thm:main} A uniform deterministic algorithm returns exactly all vertices from which Max can force~\eqref{eq:objective} against every Min strategy. For an absolute constant $C>0$, it uses at most \[ 2^{C(\log_2(L+2))^2} \] bit operations. The number of distinct priorities and the magnitudes of the rewards are unrestricted.
[proposition] [Mean-payoff input]\label{prop:mp-interface} For a finite nonempty total arena $H$ with signed binary integer weights, its ordinary mean-payoff winning set \[ U_{\mathrm{mp}}(H)= \{v:\text{Max can force liminf mean payoff at least }0\} \] is computable deterministically in $2^{O((\log_2(L_H+2))^2)}$ bit operations, where $L_H$ is its full binary encoding length. There is a single positional Max strategy winning from every vertex of $U_{\mathrm{mp}}(H)$, and a single positional Min strategy forcing strictly negative liminf mean payoff from every vertex outside it. Both guarantees hold against every history-dependent opposing strategy.
[theorem] \label{thm:determinacy} In every finite arena, each vertex is winning for exactly one of \Max\ and \Min. From each vertex winning for \Max, there is a conjunction-winning strategy satisfying \eqref{eq:uniform-prefix}.

--- MANUSCRIPT: Deterministic quasipolynomial-time mean-payoff games (September-25-2026)
ABSTRACT: We give a deterministic algorithm that computes the complete zero-threshold winning set of a finite mean-payoff game with arbitrary signed integer edge weights encoded in binary. For total explicit input length L, it uses $`2^{O((\log(L+2))^2)}`$ bit operations. A reduction also computes the exact rational value at every vertex and globally optimal positional strategies for both players within the same quasipolynomial bound.
[theorem] \label{thm:main} A uniform deterministic algorithm returns exactly the set \[ U=\bigl\{v\in V:\exists\text{ Max strategy }\sigma\ \forall\text{ Min strategies }\tau, \ \MP_w(\pi_{v,\sigma,\tau})\ge0\bigr\} \] for every game specified above. For an absolute constant $C>0$, the complete computation uses at most \[ 2^{C(\log_2(L+2))^2} \] bit operations in a standard model polynomially equivalent to a uniform deterministic Turing machine. The bound includes preprocessing, exact arithmetic, recursion, and output of the entire set $U$.
[proposition] [Winning partition from the wide box] \label{prop:game-reduction} Let $h$ be the box solution in $[0,D_0]^V$. Then \[ V_{\lo}=\{i:h_i\le nW\},\qquad V_{\hi}=\{i:h_i\ge D_0-nW\} \] partition $V$. There is a positional Max strategy under which every play starting in $V_{\hi}$ has original mean payoff at least zero. There is a positional Min strategy under which every play starting in $V_{\lo}$ has original upper limiting average at most $-1/n$. Both assertions allow arbitrary history-dependent opposition.
[theorem] [Simultaneous labelling] \label{thm:labelling} For every input in Equation~\eqref{eq:recursive-input}, the procedure $\Label(A,D,a,b)$ of Section~\ref{sec:algorithm} terminates and returns a vector in $\{+,-\}^V$. It assigns $+$ to every index claimed by any Max witness and $-$ to every index claimed by any Min witness.

--- MANUSCRIPT: Randomized quasipolynomial-time mean-payoff games (September-25-2026)
ABSTRACT: We give a randomized algorithm that computes the complete zero-threshold winning set of a finite mean-payoff game with arbitrary signed integer edge weights encoded in binary. For total explicit input length L, it uses $`2^{O((\log(L+2))^2)}`$ bit operations on every random tape and is correct with probability at least 7/8. A polynomial-time check certifies the winning regions and positional strategies for both players or reports failure. Independent repetition therefore gives an always-correct algorithm with the same expected quasipolynomial bit bound.

For an absolute constant $C>0$, on every random tape its total cost is at most \[ 2^{C(\log_2(L+2))^2} \] bit operations in a standard model polynomially equivalent to a uniform probabilistic Turing machine. The bound includes preprocessing, recursive calls, intermediate arithmetic, and random-bit generation.
