=== MANUSCRIPT: Bounded-degree coboundary expanders in every dimension (September-24-2026) [preprints/Bounded-degree-coboundary-expanders-in-every-dimension-September-24-2026/build/source/main.tex]
ABSTRACT: For every integer d ≥ 3, we construct arbitrarily large finite d-dimensional simplicial complexes with uniformly bounded vertex degrees and uniform 𝔽2 coboundary expansion in every degree below d. Together with the known graph and two-dimensional cases, this establishes the existence of bounded-degree 𝔽2 coboundary expanders in every positive dimension.
INTRODUCTION (start): \label{sec:introduction} In an expander graph, the edge boundary of a set of vertices controls its distance from the empty set or the whole vertex set. Coboundary expansion extends this condition to sets of faces in a simplicial complex. Over $\F$, the coboundary of a set of $i$-faces consists of the $(i+1)$-faces containing an odd number of them. We construct complexes of increasing size for which this boundary controls distance from the space of coboundaries, uniformly in the size and with a bounded number of top-dimensional faces at each vertex. Let $Y$ be a finite pure $s$-dimensional simplicial complex, and let $Y(i)$ denote its faces with $i+1$ vertices. Purity means that every face is contained in an $s$-face. Write $C^i(Y;\F)$ for the functions from $Y(i)$ to $\F$. We use the weights \begin{equation}\label{eq:weights} w_i^Y(\sigma)= \frac{\#\{\tau\in Y(s):\sigma\subseteq\tau\}} {\binom{s+1}{i+1}\,|Y(s)|}, \qquad \norm{f}_{Y,i}=\sum_{\sigma:\,f(\sigma)\ne0}w_i^Y(\sigma). \end{equation} Equivalently, sample an $s$-face uniformly and then one of its $i$-faces uniformly; $\norm{f}_{Y,i}$ is the probability that $f$ is nonzero there. All simplicial chains and cochains have coefficients in $\F$ unless specified otherwise. The coboundary is \[ (\delta_i f)(\tau)=\sum_{\substack{\sigma\subset\tau\\|\sigma|=i+1}} f(\sigma)\quad\text{in }\F. \] Write $Z^i(Y)=\ker\delta_i$ and $B^i(Y)=\im\delta_{i-1}$, taking $B^0(Y)$ to be the constant functions. For a subspace $A\subseteq C^i(Y;\F)$, put \[ \dist_{Y,i}(f,A)=\min_{a\in A}\norm{f-a}_{Y,i}. \] Thus $Z^0(Y)=B^0(Y)$ when $Y$ is connected. [statement] The distinction between cocycles and coboundaries is essential. If $f\in Z^i(Y)\setminus B^i(Y)$, its coboundary vanishes while its distance from $B^i(Y)$ is positive. Thus \eqref{eq:goal} requires the vanishing of $H^i(Y;\F)=Z^i(Y)/B^i(Y)$, with reduced cohomology understood in degree zero. A uniform inequality against $Z^i(Y)$ alone allows nonzero cohomology. Our proof supplies both that quantitative inequality and the required vanishing for the same complexes. \paragraph{Prior work.} The higher-dimensional coisoperimetric viewpoint developed through the random-complex work of Linial and Meshulam \cite{LM2006} and Meshulam and Wallach \cite{MW2009}. Their models retain a complete lower skeleton and study the disappearance of cohomology as top-dimensional faces are added. Gromov connected cohomological filling inequalities with topological overlap and asked for arbitrarily large complexes with bounded vertex incidence and uniform filling bounds \cite[Sections~2.3--2.5 and~2.14]{Gromov2010}. The full coboundary expansion problem also demands vanishing cohomology; a recent formulation is \cite[Problem~1.3]{CL2025}. There are two different degree conditions in this history. Lubotzky and Meshulam constructed random Latin-square coboundary expanders in dimension two \cite{LM2015}; Lubotzky, Luria, and Rosenthal constructed random Steiner-system coboundary expanders in every dimension \cite{LLR2019}. These results bound the number of top-dimensional faces through a codimension-one face. The Latin-square complexes have a complete tripartite $1$-skeleton, and the Steiner-system complexes have a complete $(d-1)$-skeleton. In dimensions at least two, vertex degrees grow with the size. The degree bound in \cref{thm:main} is at vertices. For bounded vertex degree, Kaufman, Kazhdan, and Lubotzky established cosystolic and topological expansion for two-dimensional skeleta of Ramanujan complexes \cite{KKL2016}. Evra and Kaufman obtained bounded-degree cosystolic expanders in every dimension through a local-to-global theorem \cite{EK2024}. The associated expansion methods include the building-like complexes of Lubotzky, Meshulam, and Mozes \cite{LMM2016}, the strongly symmetric complexes of Kaufman and Oppenheim \cite{KO2021}, the coefficient-independent methods of Kaufman and Mass \cite{KM2021}, and the quantitative local-to-global results of Dikstei […]
[theorem] \label{thm:main} For every integer $d\ge3$, there exist constants $D<\infty$, $\eps>0$, and finite connected pure $d$-dimensional simplicial complexes $X_m$, with $|X_m(0)|\longrightarrow\infty$, such that every vertex belongs to at most $D$ faces of dimension $d$ and, for every $f\in C^i(X_m;\F)$, \begin{equation}\label{eq:goal} \norm{\delta_i f}_{X_m,i+1} \ge \eps\,\dist_{X_m,i}(f,B^i(X_m)) \qquad(0\le i<d). \end{equation} The constants are independent of $m$, $i$, and $f$.

structure Complex where
  vertexCount : ℕ
  faces : Finset (Finset (Fin vertexCount))
  empty_mem : ∅ ∈ faces
  downward : ∀ {σ τ}, σ ∈ faces → τ ⊆ σ → τ ∈ faces
  vertex_mem : ∀ v, {v} ∈ faces
namespace Complex
def facesOf (X : Complex) (i : ℕ) : Finset (Finset (Fin X.vertexCount)) :=
  X.faces.filter (fun σ => σ.card = i + 1)
def Face (X : Complex) (i : ℕ) := {σ // σ ∈ X.facesOf i}
instance (X : Complex) (i : ℕ) : Fintype (X.Face i) := Subtype.fintype _
instance (X : Complex) (i : ℕ) : DecidableEq (X.Face i) := Classical.decEq _
def Pure (X : Complex) (s : ℕ) : Prop :=
  (X.facesOf s).Nonempty ∧
  ∀ σ ∈ X.faces, ∃ τ ∈ X.facesOf s, σ ⊆ τ
def Connected (X : Complex) : Prop :=
  Nonempty (Fin X.vertexCount) ∧
  ∀ v w : Fin X.vertexCount,
    Relation.ReflTransGen (fun a b => a ≠ b ∧ {a, b} ∈ X.faces) v w
abbrev Cochain (X : Complex) (i : ℕ) := X.Face i → ZMod 2
def weight (X : Complex) (s i : ℕ) (σ : X.Face i) : ℝ :=
  (((X.facesOf s).filter (fun τ => σ.val ⊆ τ)).card : ℝ) /
    ((Nat.choose (s + 1) (i + 1) : ℝ) * (X.facesOf s).card)
def norm (X : Complex) (s i : ℕ) (f : X.Cochain i) : ℝ :=
  ∑ σ : X.Face i, if f σ ≠ 0 then X.weight s i σ else 0
def coboundary (X : Complex) (i : ℕ) (f : X.Cochain i) : X.Cochain (i + 1) :=
  fun τ => ∑ σ : X.Face i, if σ.val ⊆ τ.val then f σ else 0
def coboundaries (X : Complex) : (i : ℕ) → Set (X.Cochain i)
  | 0 => {f | ∃ c : ZMod 2, f = fun _ => c}
  | i + 1 => Set.range (X.coboundary i)
def distance (X : Complex) (s i : ℕ) (f : X.Cochain i)
    (A : Set (X.Cochain i)) : ℝ :=
  sInf ((fun a => X.norm s i (f - a)) '' A)
def topDegree (X : Complex) (s : ℕ) (v : Fin X.vertexCount) : ℕ :=
  ((X.facesOf s).filter (fun τ => v ∈ τ)).card
end Complex
