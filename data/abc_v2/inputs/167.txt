SUBJECT: Combinatorics
OPENAI SUMMARY: Proves the weak pinned Erdős distance conjecture: for every fixed ε &gt; 0, all but $`o(n)`$ points of any n-point planar set determine at least $`n^{1-\varepsilon}`$ distinct nonzero distances. === MANUSCRIPT: The weak pinned planar distance theorem (September-23-2026) [preprints/The-weak-pinned-planar-distance-theorem-September-23-2026/build/main.tex]
ABSTRACT: We prove the weak pinned Erdős distinct-distance conjecture. For every fixed ε &gt; 0, all but $`o(n)`$ points of any n-point planar set determine at least $`n^{1-\varepsilon}`$ distinct nonzero distances.
INTRODUCTION (start): \label{sec:introduction} For a finite set $P\subset\R^2$ and a point $x\in P$, write \[ D_x(P)=\{\lVert y-x\rVert_2:y\in P\setminus\{x\}\}. \] The weak pinned Erd\H{o}s distinct-distance conjecture asserts that, for every $\varepsilon>0$, every sufficiently large $n$-point planar set has a point $x$ with $|D_x(P)|\ge n^{1-\varepsilon}$. Erd\H{o}s explicitly stated this question in 1957 \cite[Problem~16]{Erdos1957}; the modern terminology appears, for example, in \cite[Conjecture~4.7]{WeakPinned2025}. We resolve it positively by proving a uniform assertion about distance multiplicities at their individual pins. Its consequence will give the stated number of distances at all but $o(n)$ pins. For distinct $x,y\in P$, define the \emph{distance fiber size} \[ k_P(x,y)=\bigl|\{z\in P\setminus\{x\}: \lVert z-x\rVert_2=\lVert y-x\rVert_2\}\bigr|. \] This counts $y$ itself. Different pairs use their own source point $x$; the definition does not pool pairs having one common numerical distance. For $n\ge2$ and $s>0$, put \[ F_n(s)=\sup_{\substack{P\subset\R^2\\|P|=n}} \frac{\bigl|\{(x,y)\in P^2:x\ne y,\ k_P(x,y)\ge n^s\}\bigr|}{n(n-1)}. \] [statement] No hypothesis on separation, general position, or the coordinates is imposed. The convergence is uniform over all configurations. Its exponent $s$ is fixed; the theorem supplies no explicit rate of decay. [statement] \begin{proof} For $\varepsilon\ge1$, every pin in a set of at least two points already has at least one distance. Suppose $0<\varepsilon<1$, and take $s=\varepsilon/2$. At a pin with fewer than $n^{1-\varepsilon}$ distance classes, fewer than $n^{1-\varepsilon+s}$ neighbors lie in classes of size less than $n^s$. Each such pin therefore contributes at least $n-1-n^{1-\varepsilon/2}$ pairs counted by $F_n(s)$. If there are $b$ such pins, then, for all sufficiently large $n$, \[ \frac bn\le \frac{(n-1)F_n(\varepsilon/2)}{n-1-n^{1-\varepsilon/2}} \longrightarrow0. \] The bound is independent of $P$. \end{proof} \subsection{Background and significance} Erd\H{o}s initiated the planar distinct-distance and repeated-distance problems in 1946 \cite{Erdos1946}. The global distinct-distance problem asks for the minimum size of the union $\bigcup_{x\in P}D_x(P)$. The square lattice gives sets for which this union has size at most a constant multiple of $n/\sqrt{\log n}$ \cite[Theorem~1]{Erdos1946}. Guth and Katz proved that every planar $n$-point set determines at least a constant multiple of $n/\log n$ distances \cite[Theorem~1.1]{GuthKatz}. Their conclusion concerns the union; the pinned question requires the distances to have a common source. The development of pinned bounds combined incidence geometry with increasingly effective counting and entropy estimates. Solymosi and T\'oth proved a pinned lower bound of order $n^{6/7}$ \cite[Theorem~1]{SolymosiToth}. Tardos improved this exponent using entropy inequalities for patterns of sums and differences \cite{Tardos2003}. Katz and Tardos refined that method to obtain every exponent below \[ \frac{48-14e}{55-16e}=0.864137\ldots \] \cite{KatzTardos}. These results guarantee one pin in every configuration. The sharper pinned conjecture asks for order $n/\sqrt{\log n}$ distances at a pin; see \cite[Introduction]{LundPetridis}. Lund and Petridis also explain the distinction between the real planar problem and pinned-distance theorems over other fields. Theorem~\ref{thm:main} controls the multiplicity of a distance chosen by sampling a distinct ordered pair. Corollary~\ref{cor:pins} makes its almost-every-pin consequence explicit and resolves the weak pinned conjecture. An exceptional set is necessary: if $P$ consists of points on a circle and its center, the center sees just one nonzero distance. \subsection{The proof in outline} Assuming that Theorem~\ref{thm:main} fails, we first choose a sequence with nearly maximal density of pairs in large distance fibers. === MANUSCRIPT: A power saving for planar unit distances (September-23-2026) [preprints/A-power-saving-for-planar-unit-distances-September-23-2026/build/main.tex]
ABSTRACT: We prove a power saving for the planar unit-distance problem: for some absolute $`\beta\lt 4/3`$, every set of n points in the Euclidean plane determines $`O(n^\beta)`$ unordered pairs at unit distance.
INTRODUCTION (start): \label{sec:introduction} For a finite set \(X\subset\R^2\), write \[ u(X)=\#\bigl\{\{x,y\}\subset X:\ \norm{x-y}_2=1\bigr\}, \qquad u(n)=\max_{\substack{X\subset\R^2\\ |X|=n}}u(X). \] Thus pairs are unordered and their endpoints are distinct. We prove a fixed power saving over the exponent \(4/3\). [statement] \Cref{thm:main} gives a positive answer to the question whether this upper exponent can be lowered by a fixed amount: equivalently, \(u(n)=O(n^{4/3-\delta})\) for an absolute \(\delta>0\). All constants are independent of the configuration. \subsection{The unit-distance problem and earlier methods} Erd\H{o}s introduced the repeated-distance problem in 1946 \cite{erdos1946}. Rescaling a configuration turns any specified positive distance into a unit distance, so the problem concerns the largest possible multiplicity of one distance. His lattice construction gives the lower bound \(n^{1+c/\log\log n}\) for a positive constant \(c\) and sufficiently large \(n\) \cite[Theorem~2]{erdos1946}. Spencer, Szemer\'edi and Trotter established the upper bound \(u(n)=O(n^{4/3})\) in 1984 \cite{sst1984}. Sz\'ekely gave a crossing-number proof and a general incidence theorem for families of curves \cite[Theorems~4 and~8]{Szekely1997}. The crossing inequality was developed independently by Ajtai, Chv\'atal, Newborn and Szemer\'edi and by Leighton \cite{ajtaiEtAl1982,leighton1983}. Sz\'ekely's incidence theorem applies to points and unit circles using two elementary properties: two unit circles meet in at most two points, and two points belong to at most two unit circles. Later work improved the leading constant \cite{agostonPalvolgyi2022} and described the structure of configurations near the extremal incidence scale \cite{katzSilier2026}. Pach, Raz and Solymosi connected the problem to rigidity and obtained a logarithmic improvement conditional on a rigidity conjecture \cite[Conjecture~7 and Theorem~8]{pachRazSolymosi2026}. The historical unit-distance conjecture of Erd\H{o}s proposed the stronger bound \(u(n)=n^{1+o(1)}\). An OpenAI construction disproved it by giving at least \(n^{1+\varepsilon}\) unit distances, for some fixed \(\varepsilon>0\), along an unbounded sequence of sizes \cite[Theorem~1.1]{openaiUnitLower2026}. Alon et al.\ gave a simplified account and explained the construction's number-theoretic ancestry \cite[Sections~1.2--1.3]{alonEtAl2026}. They credit the class-group ideas to Michel, Soundararajan, Ellenberg and Venkatesh. The construction combines these ideas with Golod--Shafarevich number-field towers having prescribed splitting, including the tower-cutting method of Hajir, Maire and Ramakrishna \cite{ellenbergVenkatesh2007,golodShafarevich1964,hajirMaireRamakrishna2021}. Sawin sharpened the construction to \(u(n)\gg n^{1.014114}\) along an unbounded sequence of sizes \cite[Theorem~1]{sawin2026}. These are construction lower bounds. Theorem~\ref{thm:main} bounds every configuration from above, leaving a gap between the known exponents. Our proof begins with the same point--circle incidence interpretation. Random cuttings isolate a piece of the incidence graph with controlled degrees; their sampled-cell construction belongs to the framework of Clarkson and Clarkson--Shor \cite{Clarkson1987,ClarksonShor1989}. The next ingredient is information: two points sampled as neighbors of one center share little information. Entropy methods already played a role in the distinct-distance estimates of Tardos and Katz--Tardos \cite{Tardos2003,KatzTardos}. In particular, the conditional-copy argument of Katz--Tardos retains the marginal law when resampling within a class. Here that principle enters a short-history prediction lemma whose tests may depend on a neighboring center. Its exact conditional laws and the independence of the fresh test are proved in \Cref{sec:prediction}. The arithmetic input is the normalized product formula \cite{ProductFormula}. import Mathlib
namespace OAI
noncomputable section
open Filter
open scoped Topology
namespace WeakPinned
abbrev Plane := EuclideanSpace ℝ (Fin 2)
def distanceFiber (P : Finset Plane) (x y : Plane) : Finset Plane :=
  (P.erase x).filter (fun z => dist z x = dist y x)
def k (P : Finset Plane) (x y : Plane) : ℕ :=
  (distanceFiber P x y).card
def richPairs (P : Finset Plane) (s : ℝ) : Finset (Plane × Plane) :=
  (P ×ˢ P).filter (fun xy => xy.1 ≠ xy.2 ∧
    (P.card : ℝ) ^ s ≤ (k P xy.1 xy.2 : ℝ))
def pairFraction (P : Finset Plane) (s : ℝ) : ℝ :=
  (richPairs P s).card / ((P.card : ℝ) * ((P.card : ℝ) - 1))
def F (n : ℕ) (s : ℝ) : ℝ :=
  if 2 ≤ n then sSup {a : ℝ | ∃ P : Finset Plane, P.card = n ∧ a = pairFraction P s}
  else 0
theorem main (s : ℝ) (hs : 0<s) : Tendsto (fun n : ℕ => F n s) atTop (𝓝 0) := by
  sorry
end WeakPinned
end

import Mathlib
namespace OAI
namespace PlanarUnitDistances
abbrev Plane := EuclideanSpace ℝ (Fin 2)
def IsUnitPair : Sym2 Plane → Prop :=
  Sym2.lift ⟨fun x y => dist x y = 1, fun x y => by dsimp; rw [dist_comm]⟩
noncomputable def unitPairCount (X : Finset Plane) : ℕ := by
  classical
  exact (X.sym2.filter IsUnitPair).card
noncomputable def u (n : ℕ) : ℕ :=
  sSup {m : ℕ | ∃ X : Finset Plane, X.card = n ∧ unitPairCount X = m}
theorem main : ∃ C β : ℝ, 0 < C ∧ 1 ≤ β ∧ β < (4 : ℝ) / 3 ∧
    ∀ n : ℕ, (u n : ℝ) ≤ C * (n : ℝ) ^ β := by
  sorry
end PlanarUnitDistances
end OAI
