=== MANUSCRIPT: Thompson's group F is nonamenable (September-23-2026) [preprints/Thompsons-group-F-is-nonamenable-September-23-2026/build/main.tex]
ABSTRACT: We prove that Thompson's group F is nonamenable. This confirms Geoghegan's conjecture and resolves the amenability problem for F.
INTRODUCTION (start): \label{sec:introduction} Thompson's group \(F\) consists of the increasing piecewise linear homeomorphisms of \([0,1]\) with finitely many pieces, dyadic rational breakpoints, and slopes in \(2^{\Z}\). We use the multiplication convention \(hg=h\circ g\) and regard \(F\) as a discrete group. A discrete group \(G\) is \emph{amenable} if its bounded real-valued functions admit a positive normalized left-invariant mean: a linear functional \(M:\ell^\infty(G;\R)\to\R\) satisfying \(M(1)=1\), \(M(\varphi)\ge0\) whenever \(\varphi\ge0\), and \(M(g\mapsto\varphi(hg))=M(\varphi)\) for every \(h\in G\). This invariant-mean viewpoint belongs to the classical theory developed by von Neumann and Day \cite{vonNeumann1929,Day1957}. We use the following forward implication of the F\o lner criterion \cite{Folner1955}: if \(G\) is amenable, then for every finite \(S\subset G\) and every \(\varepsilon>0\), there is a nonempty finite \(A\subset G\) such that \begin{equation}\label{eq:folner} \frac{|hA\mathbin{\triangle}A|}{|A|}<\varepsilon \qquad(h\in S). \end{equation} The modern left-translation formulation in \cite[Theorem~1.2]{Moore2013} bounds the sum of these ratios and hence implies each strict individual bound by taking a smaller tolerance. Thus amenability requires finite sets whose relative boundaries are simultaneously small under any fixed finite family of translations. Thompson introduced \(F\) in 1965; an early published construction appears in McKenzie and Thompson \cite{McKenzieThompson1973}, with the identification explained by Cannon, Floyd, and Parry \cite[pp.~215--216]{CannonFloydParry1996}. The latter authors record Geoghegan's 1979 conjecture that \(F\) is nonamenable \cite[p.~227]{CannonFloydParry1996}. We prove this conjecture. [statement] \paragraph{Context and prior work.} Two classical structural facts help explain the difficulty of the amenability problem. Brin and Squier show that \(F\) contains no nonabelian free subgroup \cite[Theorem~3.1]{BrinSquier1985}, so the familiar free-subgroup obstruction does not apply. Yet \(F\) is not elementary amenable \cite[Theorem~4.10]{CannonFloydParry1996}: it lies outside the class generated by finite and abelian groups under subgroups, quotients, extensions, and directed unions. Neither fact decides ordinary amenability. The group also has strong topological finiteness properties: Brown and Geoghegan construct a classifying space with finitely many cells in each dimension \cite{BrownGeoghegan1984}. Finite approximations have provided several ways to study the remaining question. Moore proves tower lower bounds on the sizes of possible F\o lner sets \cite[Theorem~1.1]{MooreFolner2013} and characterizes amenability of \(F\) by a scalar convex Ramsey property for finite rooted ordered binary trees \cite[Theorem~3.1]{Moore2013}. Guba improves densities of finite Cayley subgraphs \cite{Guba2025Density} and derives restrictions on right-invariant means from a partition into seven diagram-defined classes \cite{Guba2026}. From an operator-algebraic direction, Haagerup and Olesen prove that simplicity of the reduced group \(C^*\)-algebra of Thompson's group \(T\) would imply nonamenability of \(F\) \cite[Theorem~5.5]{HaagerupOlesen2017}. These results expose constraints on amenability through finite sets, trees, diagrams, and representations. The proof below uses finite dyadic partitions and scalar correlations of Hilbert-valued colors. There have also been claims of a complete resolution in both directions. Akhmedov's 2021 version claims nonamenability through a height-function criterion \cite{Akhmedov2021}. Shavgulidze claimed amenability \cite{Shavgulidze2009}; Moore identified errors in that approach \cite{Moore2011Critique}. Moore separately withdrew an amenability claim after Akhmedov identified an error in Lemma~4.13 of that manuscript \cite{Moore2012Withdrawn}. abbrev UnitInterval := Set.Icc (0 : ℝ) 1
def unitIntervalZero : UnitInterval := ⟨0, le_rfl, zero_le_one⟩
def unitIntervalOne : UnitInterval := ⟨1, zero_le_one, le_rfl⟩
structure IntervalHomeomorph where
  toHomeomorph : UnitInterval ≃ₜ UnitInterval
namespace IntervalHomeomorph
instance : CoeFun IntervalHomeomorph (fun _ => UnitInterval → UnitInterval) :=
  ⟨fun f => f.toHomeomorph⟩
end IntervalHomeomorph
def IsDyadic (x : ℝ) : Prop :=
  ∃ (k : ℤ) (n : ℕ), x = (k : ℝ) / (2 : ℝ) ^ n
structure DyadicPLWitness (f : IntervalHomeomorph) where
  pieceCount : ℕ
  positive : 0 < pieceCount
  knots : Fin (pieceCount + 1) → UnitInterval
  strictMono_knots : StrictMono knots
  first : knots 0 = unitIntervalZero
  last : knots (Fin.last pieceCount) = unitIntervalOne
  dyadic : ∀ i, IsDyadic (knots i : ℝ)
  cover : ∀ x : UnitInterval, ∃ i : Fin pieceCount,
    knots i.castSucc ≤ x ∧ x ≤ knots i.succ
  exponent : Fin pieceCount → ℤ
  affine : ∀ (i : Fin pieceCount) (x : UnitInterval),
    knots i.castSucc ≤ x → x ≤ knots i.succ →
    (f x : ℝ) = (f (knots i.castSucc) : ℝ) +
      (2 : ℝ) ^ exponent i * ((x : ℝ) - (knots i.castSucc : ℝ))
def HasDyadicPLPieces (f : IntervalHomeomorph) : Prop := Nonempty (DyadicPLWitness f)
def F := {f : IntervalHomeomorph // StrictMono f ∧ HasDyadicPLPieces f}
abbrev BoundedReal (G : Type uG) := lp (fun _ : G => ℝ) ∞
variable {G : Type uG} [Group G]
def leftPull (h : G) : BoundedReal G →ₗ[ℝ] BoundedReal G where
  toFun f := ⟨fun g => f (h * g), memℓp_infty ⟨‖f‖, by
    rintro y ⟨g, rfl⟩
    exact lp.norm_apply_le_norm ENNReal.top_ne_zero f (h * g)⟩⟩
  map_add' f g := by
    apply lp.ext
    funext x
    rfl
  map_smul' r f := by
    apply lp.ext
    funext x
    rfl
structure InvariantMean (G : Type uG) [Group G] where
  toLinearMap : BoundedReal G →ₗ[ℝ] ℝ
  positive : ∀ f : BoundedReal G, (∀ g, 0 ≤ f g) → 0 ≤ toLinearMap f
  normalized : toLinearMap 1 = 1
  left_invariant : ∀ (h : G) (f : BoundedReal G),
    toLinearMap (leftPull h f) = toLinearMap f
theorem thompson_F_nonamenable_composition :
    ∃ group : Group F, letI := group;
      (∀ (h g : F) (x : UnitInterval),
        (h * g).val.toHomeomorph x = h.val.toHomeomorph (g.val.toHomeomorph x)) ∧
      ¬ Nonempty (InvariantMean F) := by
  sorry
end ThompsonNonamenability
