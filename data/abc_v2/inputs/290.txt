FAMILY 290: Relative bicentralizers and modular spectral recovery
SUBJECT: Operator algebras
OPENAI SUMMARY: Proves Connes' bicentralizer conjecture for every type III1 factor with separable predual and every faithful normal state. More generally, for every inclusion $`N\subset M`$ of von Neumann algebras with separable preduals admitting a faithful normal conditional expectation, constructs an amenable expected subalgebra $`P\subset N`$ with $`P'\cap c(M)=N'\cap c(M)`$, resolving the relative bicentralizer conjecture.

=== MANUSCRIPT: Expected amenable subalgebras preserving core commutants (September-23-2026) [preprints/Expected-amenable-subalgebras-preserving-core-commutants-September-23-2026/build/paper.tex]
ABSTRACT: We prove that every inclusion $`N\subset M`$ of von Neumann algebras with separable preduals and a faithful normal conditional expectation contains an expected amenable subalgebra $`P\subset N`$ such that $`P'\cap c(M)=N'\cap c(M)`$, where $`c(M)`$ denotes the continuous core of M. This resolves the relative bicentralizer conjecture in this setting.
INTRODUCTION (start): An inclusion $N\subset M$ is \emph{expected} if it admits a faithful normal conditional expectation $E_N:M\to N$. Such an expectation makes the inclusion compatible with modular theory: a faithful normal state on $N$ extends through $E_N$ to a state on $M$ whose modular action preserves $N$. For a faithful normal state $\psi$ on $M$, the continuous core is $c(M)=M\rtimes_{\sigma^\psi}\R$, with its canonical copy of $M$. We ask whether an amenable expected subalgebra of $N$ can impose exactly the same commutation constraints as $N$ on the whole core. Equality of commutants inside $M$ alone does not answer this question: the core also contains the unitaries implementing the modular action. Our main theorem retains these additional constraints. [statement] The canonical core isomorphism associated with a change of faithful normal state fixes $M$, so the stated relative-commutant equality is independent of the state used to define the core. \paragraph{History and the relative conjecture.} Popa's solution of Kadison's problem for irreducible expected inclusions with separable preduals and type II bottom factor provides a model for finding amenable subalgebras that retain prescribed commutation properties \cite{Popa1981}. For type III factors, modular asymptotic centralization supplies a related approach. The bicentralizer of a faithful normal state consists of those elements that commute asymptotically with every bounded sequence asymptotically centralizing the state in predual norm. Connes introduced the problem of its triviality in the classification of injective factors \cite{Connes1982,Connes1985}. Haagerup solved the amenable type $\mathrm{III}_1$ case, completing the uniqueness theorem for the injective type $\mathrm{III}_1$ factor \cite{Haagerup}. For type $\mathrm{III}_1$ factors with separable predual, he characterized triviality by norm-density of faithful normal states whose centralizers have trivial relative commutant \cite[Theorem~3.1]{Haagerup}. His proof uses Popa's construction to find a maximal abelian subalgebra of such a centralizer that remains maximal abelian in the ambient factor; the expectations onto the centralizer and onto its abelian subalgebra compose \cite[proof of Theorem~3.1]{Haagerup}. Masuda introduced a relative bicentralizer in the finite-index setting \cite[Definition~4.1]{Masuda2005}. Ando, Haagerup, Houdayer, and Marrakchi constructed the canonical relative bicentralizer flow for expected inclusions with type $\mathrm{III}_1$ bottom factor \cite[Theorem~A]{AHHM}. This extends the absolute flow discovered by Haagerup and independently by Marrakchi, as described in that paper. The structural results of Houdayer and Isono \cite[Proposition~3.4 and Theorem~3.5]{HI2017} and Marrakchi's absolute flow-ergodicity theorem \cite[Theorem~D]{M0} underlie the absolute reduction used here. Marrakchi formulated the relative bicentralizer conjecture and proved that, for separable preduals, it is equivalent to the conclusion of Theorem~\ref{thm:main} \cite[Conjecture~C and Theorem~D]{M1}. Our theorem therefore resolves that conjecture positively, including inclusions with arbitrary centers and types. Marrakchi's recent Theorem B \cite{M2} gives an expected amenable subalgebra $P\subset N$ preserving $N'\cap M$ for general expected inclusions with separable preduals. Theorem~\ref{thm:main} preserves the commutant in the continuous core. Applying the earlier result with upper algebra $c(M)$ would require an expectation from $c(M)$ onto $N$, which the original inclusion does not supply. The binormal-state and zero-shift completely positive map of \cite[Lemmas~2.1 and 2.2(1)]{M2} are essential inputs to the proof below. \paragraph{The absolute problem and the recent announcement.} Houdayer and Marrakchi have announced that every type $\mathrm{III}_1$ factor admitting a faithful normal state has trivial bicentralizer \cite[Theorem~G]{HoudayerMarrakchi2026}; their theorem statement has no separability restriction. [theorem] \label{thm:main} Let $N\subset M$ be a unital inclusion of von Neumann algebras with separable preduals, and suppose that there is a faithful normal conditional expectation $E_N:M\to N$. There exist a unital amenable von Neumann subalgebra $P\subset N$ and a faithful normal conditional expectation $F:N\to P$ such that \[ P'\cap c(M)=N'\cap c(M). \] Here amenable means injective.
[corollary] \label{cor:masa} Under the hypotheses of Theorem~\ref{thm:main}, there is a maximal abelian subalgebra $A\subset N$ with a faithful normal conditional expectation $F:N\to A$ such that \[ A'\cap c(M)=c(A)\vee\bigl(N'\cap c(M)\bigr). \]

=== MANUSCRIPT: Bounded recovery for modular spectral averages (September-23-2026) [preprints/Bounded-recovery-for-modular-spectral-averages-September-23-2026/build/paper.tex]
ABSTRACT: We prove a bounded spectral recovery theorem for a von Neumann algebra with a faithful normal state whose centralizer consists only of scalars. A positive averaged squared norm for an arbitrary bounded Hilbert-space operator on shrinking modular spectral bands can be recovered on uniformly bounded algebra elements with shrinking spectral support. We apply this theorem to spectral intertwining rigidity and obtain an alternative proof of bicentralizer triviality for type III1 factors with separable predual.
INTRODUCTION (start): Spectral localization in the standard Hilbert space of a von Neumann algebra does not by itself produce uniformly bounded elements of the algebra. This distinction matters when an argument starts with spectral vectors but its asymptotic identities apply only to bounded operator sequences. Our main analytical result, \Cref{rec:bounded}, provides a bounded recovery principle for this situation. Let $M$ be a von Neumann algebra with a faithful normal state $\phi$. Write $M_\phi$ for the fixed-point algebra of its modular automorphism group $\sigma^\phi$. We call $\phi$ ergodic when $M_\phi=\C1$. On the standard Hilbert space $H=L^2(M)$, put $\xi=\phi^{1/2}$, $D=\log\Delta_\phi$, and $U_t=e^{itD}$. For an arbitrary fixed $T\in\B(H)$, consider unit vectors supported in spectral intervals of $D$ shrinking to a real number $s$. \Cref{rec:bounded} shows that a positive limiting averaged value of $\norm{TU_th}^2$ on these vectors can be recovered as a positive value of $\norm{Tv\xi}^2$ on a sequence of uniformly bounded $v\in M$. The recovered vectors remain in intervals shrinking to $s$, with widths at most four times the original widths. The averaging uses a fixed translation-invariant mean obtained from symmetric interval averages. The exact quantifiers and mean are given in \Cref{mod:average,rec:bounded}. The only structural assumption in this recovery theorem is $M_\phi=\C1$; neither a bicentralizer condition nor a second action is required. This assumption supplies a broad class of applications: Marrakchi and Vaes proved that ergodic faithful normal states form a dense $G_\delta$ in the normal state space of every type $\mathrm{III}_1$ factor with separable predual \cite[Theorem~A]{MarrakchiVaes2024}. \paragraph{Bicentralizers and prior work.} We use the predual convention \[ (w\phi)(y)=\phi(yw),\qquad (\phi w)(y)=\phi(wy). \] The bicentralizer $\BC(M,\phi)$ consists of those $a\in M$ for which $[a,w_n]\to0$ strongly whenever $(w_n)$ is uniformly bounded and $\norm{w_n\phi-\phi w_n}_{M_*}\to0$. Connes' bicentralizer conjecture asserts that this algebra is scalar for every type $\mathrm{III}_1$ factor with separable predual. Connes developed the problem in his classification program for injective factors \cite{Connes1980,Connes1985}. Haagerup proved the amenable case, completing the uniqueness theorem for the injective type $\mathrm{III}_1$ factor \cite{Haagerup1987}. Haagerup also related triviality to the existence of a faithful normal state with irreducible centralizer, meaning $(M_\phi)'\cap M=\C1$ \cite[Theorem~3.1]{Haagerup1987}. Together with Popa's work on maximal abelian subalgebras \cite{Popa1981}, this connects the problem to expected subalgebras; the expected-masa equivalence is stated in \cite[Corollary~3.6]{HI2017}. Important nonamenable cases include Houdayer's theorem for free Araki--Woods factors \cite{Houdayer2009} and the semisolid factors treated by Houdayer and Isono \cite[Theorem~3.7]{HI2017}. An irreducible centralizer in these results is different from the scalar centralizer assumed in our recovery theorem. Houdayer and Isono proved that a nonscalar bicentralizer of a separable type $\mathrm{III}_1$ factor is itself a type $\mathrm{III}_1$ factor and equals its own bicentralizer for the restricted state \cite[Proposition~3.4 and Theorem~3.5]{HI2017}. Ando, Haagerup, Houdayer, and Marrakchi established the canonical relative bicentralizer flow \cite[Theorem~A]{AHHM2020}, following the flow construction of Haagerup and its independent discovery by Marrakchi. Marrakchi proved that every nonidentity time of the absolute flow is ergodic, without a fullness assumption \cite[Theorem~D]{Marrakchi2020}. [theorem] [Spectral intertwining rigidity]\label{thm:rigidity} Let $M$ be a von Neumann algebra with a faithful normal state $\phi$ such that $M_\phi=\C1$. Let $b:\R\curvearrowright M$ be a continuous $\phi$-preserving action. Suppose that, for every $s\in\R$, every uniformly bounded sequence $(w_n)$ in $M$, and every $a\in M$, \begin{equation}\label{eq:flow-property} \norm{\phi w_n-e^s w_n\phi}_{M_*}\longrightarrow0 \quad\Longrightarrow\quad w_na-b_s(a)w_n\longrightarrow0 \quad\text{strongly}. \end{equation} Then $b_s=\id_M$ for every $s\in\R$.

def spectralCharacter (t : ℝ) : BoundedContinuousFunction ℝ ℂ :=
  BoundedContinuousFunction.ofNormedAddCommGroup
    (fun u : ℝ => Complex.exp (((t * u : ℝ) : ℂ) * Complex.I))
    (by fun_prop) 1 (by intro u; simp [Complex.norm_exp])
def halfExponentialCutoff (n : ℕ) : BoundedContinuousFunction ℝ ℂ :=
  BoundedContinuousFunction.ofNormedAddCommGroup
    (fun u : ℝ => (Real.exp (min (n : ℝ) u / 2) : ℂ))
    (by fun_prop) (Real.exp ((n : ℝ) / 2)) (by
      intro u
      simp only [Complex.norm_real, Real.norm_eq_abs, abs_of_pos (Real.exp_pos _)]
      exact Real.exp_le_exp.mpr (div_le_div_of_nonneg_right (min_le_left _ _) (by norm_num)))
structure RealSpectralCalculus (H : Type u) [NormedAddCommGroup H]
    [InnerProductSpace ℂ H] [CompleteSpace H] where
  calculus : (BoundedContinuousFunction ℝ ℂ) →⋆ₐ[ℂ] (H →L[ℂ] H)
  nondegenerate : Dense {h : H | ∃ f : BoundedContinuousFunction ℝ ℂ,
    HasCompactSupport (f : ℝ → ℂ) ∧ ∃ k : H, calculus f k = h}
namespace RealSpectralCalculus
def unitary (D : RealSpectralCalculus H) (t : ℝ) : H →L[ℂ] H :=
  D.calculus (spectralCharacter t)
def halfGraph (D : RealSpectralCalculus H) : Set (H × H) :=
  {p | Tendsto (fun n : ℕ => D.calculus (halfExponentialCutoff n) p.1) atTop (𝓝 p.2)}
def HasSpectralSupport (D : RealSpectralCalculus H) (I : Set ℝ) (h : H) : Prop :=
  ∀ f : BoundedContinuousFunction ℝ ℂ, (∀ u ∈ I, f u = 0) → D.calculus f h = 0
end RealSpectralCalculus

  xi : H
  norm_xi : ‖xi‖ = 1

  separating : ∀ a : H →L[ℂ] H, a ∈ M → a xi = 0 → a = 0
  D : RealSpectralCalculus H
