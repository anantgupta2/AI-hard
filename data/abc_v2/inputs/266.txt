FAMILY 266: Exactly three mutually unbiased bases in dimension six
SUBJECT: Mathematical physics
OPENAI SUMMARY: Proves $`N(6)=3`$, resolving Zauner's dimension-six mutually unbiased bases conjecture: three such bases exist in ℂ6, but four cannot. The exclusion is a complete certified computation under the stated binary64 arithmetic and compiler conditions. An independent companion proves the Matolcsi–Ruzsa–Weiner Fourier-vanishing conjecture for order-six complex Hadamard matrices outside Tao's cubic equivalence class.

=== MANUSCRIPT: The maximum number of mutually unbiased bases in dimension six (September-24-2026) [preprints/The-maximum-number-of-mutually-unbiased-bases-in-dimension-six-September-24-2026/build/paper.tex]
ABSTRACT: We prove that the maximum number of mutually unbiased orthonormal bases in ℂ6 is three, resolving Zauner's dimension-six MUB conjecture. The upper bound is computer-assisted: under the stated binary64 arithmetic and compiler conditions, a complete execution of the documented verification pipeline excludes four arbitrary complex bases.
INTRODUCTION (start): \label{sec:introduction} Two orthonormal bases $\mathcal B$ and $\mathcal C$ of $\C^d$ are \emph{mutually unbiased} if \[ |\langle b,c\rangle|^2=\frac1d \qquad(b\in\mathcal B,\ c\in\mathcal C). \] Here $\langle u,v\rangle=\sum_j\overline{u_j}v_j$. For $d\ge2$, let $N(d)$ be the largest number of pairwise mutually unbiased orthonormal bases in $\C^d$. Our main result is the following. [statement] A common unitary transformation makes one basis the coordinate basis. The second is then the column basis of $H/\sqrt6$, where $H$ is a complex matrix satisfying \[ |H_{ij}|=1,\qquad HH^*=6I. \] Such an unscaled matrix is called a complex Hadamard matrix. The upper-bound problem is to exclude an extension of this pair by \emph{two} further bases, for every possible $H$. The second basis is unrestricted: the argument covers arbitrary complex Hadamard matrices, including those outside previously studied families. \subsection{Historical context and scope} Mutually unbiased bases describe projective measurements for which a state from one basis produces the uniform outcome distribution in every other basis. This finite-dimensional form of complementarity appears in Schwinger's unitary-operator framework~\cite{Schwinger1960Unitary}. Ivanovi\'c developed the state-determination problem and prime-dimensional constructions~\cite{Ivanovic1981StateDetermination}; Wootters and Fields proved the statistical optimality of complete sets for state determination and constructed them in every prime-power dimension \cite{WoottersFields1989}. One has $N(d)\le d+1$; an operator-space proof and further prime-power constructions are given in \cite{BandyopadhyayEtAl2002}. Dimension six is the first dimension outside the prime-power class. The tensor-product construction gives three bases in $\C^6$ \cite[Section~4]{KlappeneckerRotteler2004}. Zauner's dimension-six MUB conjecture asserts that this lower bound is sharp. Its origin is traced to his 1991 diploma thesis~\cite{Zauner1991Diploma}; see also the historical account in~\cite[Section~2.3]{McNultyWeigert2026Review}. His doctoral thesis states the corresponding quantum-design conjecture \cite[Section~3.3]{Zauner1999}, later translated in~\cite{Zauner2011}. The equation $N(6)=3$ appears explicitly as Conjecture~1 of \cite[Section~4]{KlappeneckerRotteler2004}. Several complementary approaches developed the dimension-six problem. Grassl proved that the standard--Fourier pair cannot belong to four mutually unbiased bases~\cite[Theorem~2]{Grassl2004SICMUB6}. Bengtsson and collaborators studied its unbiased vectors and the surrounding landscape of Hadamard families \cite{BengtssonEtAl2007MUBHadamard}. Numerical searches by Butterley and Hall~\cite{ButterleyHall2007Numerical} and by Brierley and Weigert \cite{BrierleyWeigert2008} supplied evidence for the conjecture. Brierley and Weigert also used algebraic equations to enumerate unbiased vectors for specified Hadamards~\cite{BrierleyWeigert2009}; their Section~3.4 supplies rigorous approximation bounds for exact input matrices, while their Section~4.3 explains the limitations introduced by rounding coefficients in sampled non-affine families. The closest antecedent of the present proof is the certified discretization of Jaming, Matolcsi, M\'ora, Sz{\"o}ll{\H o}si and Weiner. They proved that the standard basis together with any member of the two-parameter Fourier family cannot be extended to four bases \cite[Theorem~1.4]{JamingEtAl2009}. Their Section~3 combines phase intervals, rigorous error bounds, subdivision, and exhaustive compatibility tests. Jaming, Matolcsi and M\'ora subsequently formulated an unrestricted discretization program \cite[Sections~2--4]{JamingMatolcsiMora2010}. The present proof completes an exhaustive cover of arbitrary second bases. The completion and displacement estimates described below reduce this cover to a finite search with certified error bounds. === MANUSCRIPT: Exact Fourier certificates for complex Hadamard matrices of order six (September-24-2026) [preprints/Exact-Fourier-certificates-for-complex-Hadamard-matrices-of-order-six-September-24-2026/build/paper.tex]
ABSTRACT: We prove the Fourier-vanishing conjecture of Matolcsi, Ruzsa, and Weiner: every complex Hadamard matrix of order six outside Tao's cubic equivalence class has a vanishing character sum at every permutation of $`(1,1,1,-1,-1,-1)`$. We also give an exact certificate excluding seven mutually unbiased bases in ℂ6; by Weiner's completion theorem, this yields an upper bound of five. Both certificates use only integer and rational arithmetic, and the complete verifier is included.
INTRODUCTION (start): \label{sec:introduction} A complex Hadamard matrix of order six is a matrix $H\in\T^{6\times6}$ with $H^*H=6I$, where $\T=\{z\in\C:|z|=1\}$. Its columns become an orthonormal basis after normalization by $1/\sqrt6$. The same columns are also points of the torus $\T^6$, and their character sums record constraints that orthogonality places on their phases. We study the normalized sums \begin{equation}\label{eq:g-definition} g_H(a)=\frac16\sum_{k=0}^5\prod_{i=0}^5H(i,k)^{a_i}, \qquad a\in\Z^6,\quad\sum_{i=0}^5a_i=0. \end{equation} The balancing condition makes these sums invariant under multiplying individual columns by phases. Write $e_0,\ldots,e_5$ for the standard coordinate vectors. Orthogonality gives $g_H(e_i-e_j)=0$ for $i\ne j$. A more restrictive vanishing at the charge \[ \alpha=(1,1,1,-1,-1,-1) \] was conjectured by Matolcsi, Ruzsa, and Weiner \cite[Conjecture~2.3]{MatolcsiRuzsaWeiner2013}. It links a degree-six character to the structure of an individual Hadamard matrix, without assuming that the matrix belongs to a larger family of unbiased bases. The conjecture has one exceptional equivalence class. Here two Hadamard matrices are equivalent if they differ by row and column permutations and by multiplication of individual rows and columns by elements of $\T$. Put $\omega=\exp(2\pi\mathrm i/3)$, and define $T=(\omega^{t_{ij}})_{i,j=0}^5$ by \begin{equation}\label{eq:cubic-matrix} t_{ij}=\begin{cases} 0,&i=0\text{ or }j=0\text{ or }i=j,\\ 1,&i,j\in\{1,\ldots,5\},\quad i-j\equiv\pm1\pmod5,\\ -1,&\text{otherwise}. \end{cases} \end{equation} This is the cubic matrix in Tao's construction \cite[p.~254]{Tao2004}; the same representative already appears in Moorhouse's study of $2$-transitive complex Hadamard matrices \cite[Example~1.1]{Moorhouse2001}. Its five noninitial indices form a cycle: adjacent indices carry the exponent $1$ and nonadjacent distinct indices carry $-1$. The matrix and its entrywise square are both Hadamard. [statement] Theorem~\ref{thm:fourier} proves the conjecture for arbitrary complex Hadamard matrices. The normalization in \eqref{eq:g-definition} divides the character sums used in \cite{MatolcsiRuzsaWeiner2013} by six and therefore leaves the vanishing assertion unchanged. Multiplying rows by phases multiplies each character by a unit scalar; together with the balancing condition, this shows that the assertion respects the stated equivalence relation. \subsection{Fourier methods and mutually unbiased bases} Two orthonormal bases in $\C^d$ are mutually unbiased if every inner product between their vectors has modulus $d^{-1/2}$. Such bases describe complementary measurements and arise in quantum state determination \cite{Ivanovic1981,WoottersFields1989}. A family contains at most $d+1$ bases, and complete families attaining that bound exist in prime-power dimensions \cite{WoottersFields1989}. The first dimension outside that construction is six. Write $N(6)$ for the maximum size of a mutually unbiased family in $\C^6$. Fixing one basis identifies every other unbiased basis with a complex Hadamard matrix. Matolcsi developed a Fourier and Delsarte approach to the resulting constraints on torus points \cite{Matolcsi2012}. Matolcsi, Ruzsa, and Weiner developed identities for the associated character sums and formulated the vanishing conjecture addressed here \cite{MatolcsiRuzsaWeiner2013}. Maxwell and Brierley proved that vanishing for the Karlsson family \cite[Theorem~4.1]{MaxwellBrierley2015}. Theorem~\ref{thm:fourier} removes the family restriction. The exceptional matrix is usually denoted $S_6$ in the Hadamard literature \cite[Section~5.6.4]{TadejZyczkowski2006}; Section~\ref{sec:cubic} gives the precise identification with \eqref{eq:cubic-matrix}. The structural step has a separate antecedent. Lison\v{e}k introduced \emph{S-Hadamard matrices}, for which both $H$ and $H^{\circ2}$ are Hadamard \cite[Definition~2.1]{Lisonek2019}. Phangara conjectured that every order-six S-Hadamard matrix is equivale […]
[theorem] [Fourier vanishing]\label{thm:fourier} Let $H$ be a complex Hadamard matrix of order six. If $H$ is not equivalent to the cubic matrix $T$ in \eqref{eq:cubic-matrix}, then \[ g_H(\pi\alpha)=0\qquad\text{for every coordinate permutation }\pi. \]
[theorem] [No complete family]\label{thm:main} There do not exist seven orthonormal bases $B_r=(b_{r,0},\ldots,b_{r,5})$ of $\C^6$, $1\le r\le7$, such that \[ \bigl|\langle b_{r,i},b_{s,j}\rangle\bigr|^2=\frac16 \qquad(r\ne s,\ 0\le i,j\le5). \]

import Mathlib
namespace OAI

open scoped BigOperators ComplexConjugate
namespace MUB6
abbrev Coord := Fin 6
abbrev CMatrix := Matrix Coord Coord ℂ
abbrev Charge := Coord → ℤ
def IsHadamard (H : CMatrix) : Prop :=
  (∀ i j, Complex.normSq (H i j) = 1) ∧
  H.conjTranspose * H = (6 : ℂ) • (1 : CMatrix)
def character (x : Coord → ℂ) (a : Charge) : ℂ := ∏ i, x i ^ a i
def g (H : CMatrix) (a : Charge) : ℂ :=
  (6 : ℂ)⁻¹ * ∑ k, character (fun i => H i k) a
def alpha : Charge := ![1, 1, 1, -1, -1, -1]
def permuteCharge (π : Equiv.Perm Coord) (a : Charge) : Charge := a ∘ π
def Equivalent (H K : CMatrix) : Prop :=
  ∃ (r c : Equiv.Perm Coord) (u v : Coord → ℂ),
    (∀ i, Complex.normSq (u i) = 1) ∧ (∀ j, Complex.normSq (v j) = 1) ∧
    ∀ i j, K i j = u i * H (r i) (c j) * v j
def omega : ℂ := Complex.exp (2 * Real.pi * Complex.I / 3)
def taoExponent : Matrix Coord Coord ℕ :=
  !![0, 0, 0, 0, 0, 0;
     0, 0, 1, 2, 2, 1;
     0, 1, 0, 1, 2, 2;
     0, 2, 1, 0, 1, 2;
     0, 2, 2, 1, 0, 1;
     0, 1, 2, 2, 1, 0]
def tao : CMatrix := fun i j => omega ^ taoExponent i j
abbrev Space := EuclideanSpace ℂ Coord
abbrev Basis := OrthonormalBasis Coord ℂ Space
def IsMUBFamily {n : ℕ} (B : Fin n → Basis) : Prop :=
  ∀ r s, r ≠ s → ∀ i j,
    Complex.normSq (inner ℂ (B r i) (B s j)) = (1 : ℝ) / 6
def Attainable (n : ℕ) : Prop := ∃ B : Fin n → Basis, IsMUBFamily B
theorem fourier_and_family_bound :
    (∀ H : CMatrix, IsHadamard H → ¬Equivalent H tao →
      ∀ π : Equiv.Perm Coord, g H (permuteCharge π alpha) = 0) ∧
    (∀ n : ℕ, Attainable n → n ≤ 5) := by
  sorry
end MUB6

def Unimodular (H : Matrix6) : Prop := ∀ i j, ‖H i j‖ = 1

  Unimodular H ∧ H.conjTranspose * H = (6 : ℂ) • (1 : Matrix6)
def entrywiseSquare (H : Matrix6) : Matrix6 := fun i j => H i j ^ 2
noncomputable def cubeFiber (v : Index → ℂ) (z : ℂ) : Finset Index := by
  classical
  exact Finset.univ.filter (fun i => v i ^ 3 = z)
noncomputable def rowRatio (H : Matrix6) (i j : Index) : Index → ℂ :=
  fun k => H i k * star (H j k)
